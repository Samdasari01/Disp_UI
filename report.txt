1. PROJECT OVERVIEW
================================================================================

The Advanced Radiation Gamma Monitor (A.R.G.M.) is a field-deployable
radiation detection and soldier tracking system designed for military and
hazardous environment operations. The system provides real-time radiation
dose monitoring, GPS-based soldier location tracking, and wireless data
relay to a central command station running a desktop monitoring application.

The system operates across three layers:

  Layer 1: Field Device (ESP32 + Geiger + GPS + Sensors)
           -> Collects radiation data and soldier GPS location
           -> Transmits averaged data to relay unit every 30 seconds

  Layer 2: Relay Device (ESP32 + WiFi/LoRa)
           -> Receives data from field units
           -> Forwards aggregated data to command station

  Layer 3: Command Station (Electron Desktop App + Libre Map)
           -> Displays real-time soldier locations on interactive map
           -> Shows radiation levels, alerts, and historical data

3.2 Data Packet Structure (Field -> Relay)
--------------------------------------------------------------------------------

  The field device averages all sensor readings over a 30-second window
  before transmitting, reducing bandwidth and power consumption.

  Field               Type        Description
  ------------------  ----------  ----------------------------------------
  device_id           uint8       Unique soldier/unit identifier
  dose_rate_avg       float       Average uSv/h over 30 seconds
  cps_avg             float       Average counts per second
  cpm                 uint32      Current counts per minute
  peak_rate           float       Peak dose rate in window
  accum_dose          float       Total accumulated dose
  latitude            float       GPS latitude (decimal degrees)
  longitude           float       GPS longitude (decimal degrees)
  elevation           float       GPS elevation in meters
  satellites          uint8       Number of GPS satellites locked
  temperature         float       Ambient temperature (C) [SHT30]
  humidity            float       Ambient humidity (%) [SHT30]
  battery_percent     uint8       Battery charge level
  status_level        uint8       Radiation status (0-3)
  timestamp           uint32      Uptime in seconds

5. FEATURE SPECIFICATIONS
================================================================================

5.1 Boot Sequence — Hardware Detection
--------------------------------------------------------------------------------

  On every power-up, the field device performs:

  1. Display title "A.R.G.M." with progress bar animation
  2. Probe each connected hardware module:
     - GEIGER COUNTER ..... OK / FAIL   (GPIO26 interrupt check)
     - SHT30 SENSOR ....... OK / FAIL   (I2C address 0x44 probe)
     - GPS MODULE ......... OK / FAIL   (Serial2 data availability)
     - NAV BUTTONS ........ OK / FAIL   (pullup state verification)
  3. Display summary: "DEVICES: X / 4 CONNECTED"
  4. Transition to HOME page

5.2 Radiation Detection Pipeline
--------------------------------------------------------------------------------

  Signal Path:
  Geiger Tube -> Pulse Board -> GPIO26 Falling Edge -> ISR
  -> Rolling Buffer -> CPS/CPM Calculation -> Dose Rate Conversion
  -> Display Update + Data Aggregation

  Detection Parameters:
  - Trigger:        Falling edge interrupt on GPIO26
  - Debounce:       2ms minimum between pulses
  - CPS:            1-second atomic capture window
  - CPM:            60-second rolling buffer
  - Dose Rate:      (CPM - 12 background) x 0.00812 = uSv/h
  - Tube:           J305b (123.1 CPM per uSv/h)

  Radiation Status Classification:
  - NORMAL:         < 0.5 uSv/h     (Green)
  - ELEVATED:       0.5 - 2.0       (Amber)
  - HIGH:           2.0 - 10.0      (Amber)
  - CRITICAL:       >= 10.0         (Red)

5.3 Data Aggregation (30-Second Window)
--------------------------------------------------------------------------------

  The field device maintains a 30-second averaging window before
  transmission to reduce radio traffic and provide stable readings.

  Every 1 second:
    - Capture CPS from geiger ISR
    - Store in 30-element buffer
    - Update GPS position (if available)
    - Update temperature/humidity (if available)

  Every 30 seconds:
    - Calculate average dose rate, CPS, CPM over the window
    - Package all sensor data into transmission packet
    - Send to relay ESP32
    - Reset averaging buffer

5.5 Navigation System
--------------------------------------------------------------------------------

  Supported Input Methods:

  a) Serial Commands (USB, 115200 baud):
     HOME, NAV, COUNT, MENU, SETTINGS, ABOUT, SENSORS, LOGS,
     NEXT, PREV, BACK, SELECT

  b) Physical Buttons (INPUT_PULLUP, active LOW):
     - UP     (GPIO32)  -> Previous page
     - DOWN   (GPIO33)  -> Next page
     - SELECT (GPIO27)  -> Enter menu / confirm

  Bottom navigation bar highlight auto-syncs with current page.
  300ms software debounce on all inputs.

9. CONCLUSION
================================================================================

The A.R.G.M. project has completed Phase 1 development with a fully
operational field device. The radiation detection pipeline is verified
and working with real Geiger counter hardware. The professional
dark-themed display interface provides clear, real-time radiation data
visualization. Navigation works via both serial commands and physical
buttons.

The system architecture is designed for scalability across three layers:
field units, relay infrastructure, and a central command application.
With the upcoming integration of GPS tracking, environmental sensing,
wireless data relay, and a desktop monitoring dashboard, A.R.G.M. will
provide a complete soldier radiation monitoring and location tracking
solution.

Current build is stable: zero warnings, zero errors, 26.8% flash and
7.1% RAM utilization — providing ample headroom for the planned feature
expansion across all three development phases.
